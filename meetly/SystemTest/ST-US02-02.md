# ST-US02-02: Participant truy cập chức năng chỉnh sửa

## System Test

- **Test ID**: ST-US02-02
- **Story**: US-02
- **Loại**: EXC / Integration boundary
- **Suite**: REGRESSION
- **Priority**: P1
- **Precondition**: Người dùng đã đăng nhập vào tài khoản người tham gia thông thường (Participant); đang ở Dashboard sự kiện.
- **Steps**:
  1. Đăng nhập bằng tài khoản participant.
  2. Truy cập Dashboard sự kiện.
  3. Kiểm tra các nút bấm trên thanh công cụ.
- **Test data**: Phiên đăng nhập participant thường
- **Expected result**:
  - Giao diện: Nút 'Chỉnh sửa sự kiện' hoàn toàn không hiển thị đối với tài khoản participant.
  - API: Nếu gọi PUT /api/events/{id} bằng token của participant, server trả về HTTP 403 Forbidden.
- **Trace to (requirement / BR)**: US-02/AC-002, US-02/AC-004, BR-05
- **Rationale**: Đảm bảo bảo mật phân quyền: chỉ admin mới có quyền chỉnh sửa sự kiện theo BR-05.
- **Owner**: QA Team
- **Trạng thái**: Draft
