# ST-US03-07: Truy cập Dashboard khi chưa tham gia

## System Test

- **Test ID**: ST-US03-07
- **Story**: US-03
- **Loại**: EXC
- **Suite**: REGRESSION
- **Priority**: P1
- **Precondition**: Người dùng chưa từng tham gia sự kiện, cố gắng mở trực tiếp URL Dashboard bằng ID không hợp lệ.
- **Steps**:
  1. Mở trình duyệt và truy cập URL: /events/fake-id-9999/dashboard.
- **Test data**: Event ID không hợp lệ: 'fake-id-9999'
- **Expected result**:
  - Giao diện: Hệ thống từ chối truy cập, hiển thị thông báo lỗi 'Sự kiện không tồn tại hoặc bạn chưa tham gia' và chuyển hướng về trang chủ.
  - API: Trả về HTTP 404 Not Found hoặc HTTP 403 Forbidden.
- **Trace to (requirement / BR)**: US-03/AC-007
- **Rationale**: Kiểm tra bảo vệ tài nguyên Dashboard trước các truy cập không hợp lệ.
- **Owner**: QA Team
- **Trạng thái**: Draft
