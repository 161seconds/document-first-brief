# ST-US02-01: Admin mở chức năng chỉnh sửa

## System Test

- **Test ID**: ST-US02-01
- **Story**: US-02
- **Loại**: Main
- **Suite**: SMOKE
- **Priority**: P1
- **Precondition**: Người dùng đã đăng nhập vào tài khoản Admin của sự kiện; đang ở màn hình Dashboard.
- **Steps**:
  1. Đăng nhập bằng tài khoản admin sự kiện.
  2. Truy cập Dashboard sự kiện (khu vực chứa Heatmap).
  3. Quan sát giao diện thanh công cụ.
- **Test data**: Phiên đăng nhập admin hợp lệ
- **Expected result**:
  - Giao diện: Nút 'Chỉnh sửa sự kiện' được hiển thị rõ ràng trên Dashboard. Nhấp vào nút sẽ mở modal/màn hình chỉnh sửa sự kiện.
  - API: Kiểm tra quyền trả về is_admin=true.
- **Trace to (requirement / BR)**: US-02/AC-001, US-02/AC-004, BR-05
- **Rationale**: Xác nhận quyền hạn của Admin sự kiện được phép mở chức năng chỉnh sửa trên Dashboard.
